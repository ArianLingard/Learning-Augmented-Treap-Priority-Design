全局统一设置

键序：随机打乱。

统计：每个配置 10 次随机种子，报“均值±标准差”。

预测器公平性：同组实验内，所有学习增强方法严格共用同一个预测频率 $\hat{f}_x$。

分桶与扰动：若无特殊说明，统一采用 $Q(f)=⌊f⌋$分桶，固定扰动取 $\delta∼U(0,0.25)$。

E1 常规分布下的基础性能对比

实验目的：验证在理想预测与常规规模下，学习增强 Treap 是否优于随机 Treap，以及各修正函数与 Chen 复合函数在标准分布下的基础性能差异。\
输入规定：

分布：Zipf $\alpha\in{1,1.25,2}$、对抗分布（$p_i=\frac{2(n-i+1)}{n(n+1)}$）、均匀分布。

规模：$n\in{1000,5000}$，序列长度 $m={10}^5$。

Oracle：完美频率预测器，$\hat{f}_x=f_x$。\
实验对象：

1. Random Treap（无预测基线）
2. Chen 复合 priority（$-⌊\mathrm{log}_2\mathrm{log}_2(1/w_x)⌋+U(0,1)$）
3. 平滑双对数函数 $f_1(w)=-\mathrm{log}_2(\mathrm{log}_2(1/w)+ϵ)$
4. 秩双对数映射函数 $f_3(w)=-\mathrm{log}_2(\mathrm{log}_2(1/p)+ϵ)$

CDF 平滑秩双对数函数 $f_4(w)=-\mathrm{log}_2(\mathrm{log}_2(1/(F(w)+1/n))+ϵ)$\
衡量指标：总比较次数、平均深度、最大深度。\
输出格式：表 1（行=分布，列=5 种方法，单元格为总比较次数均值±标准差）；图 1（Zipf $\alpha=1$时的分组柱状图）。\
预期效果：Zipf 下 Chen 与 $f_1$最优；对抗分布下 Chen 性能崩塌，$f_3,f_4$ 显著占优；均匀分布下各学习增强方法表现接近且均优于 Random。\
其他补充：此实验仅做宏观性能摸底，不涉及极端长尾或噪声。

E2 绝对量纲漂移的鲁棒性测试

实验目的：单一验证 Chen 与 $f_1$依赖绝对权重量纲，而秩映射类方法（$f_3,f_4$）对严格单调变换具备尺度不变性。\
输入规定：

分布：Zipf $\alpha=1$，$n=5000$，$m={10}^5$。

Oracle：对完美频率进行数学变换：

1. 缩放：$\hat{w}_x=c⋅(f_x/m)$，$c\in{0.1,10}$；
2. 幂律：$\hat{w}_x={(f_x/m)}^\beta$，$\beta\in{0.5,2}$。

实验对象：

1. Chen 复合 priority
2. 平滑双对数函数 $f_1$
3. 秩双对数映射函数 $f_3$
4. CDF 平滑秩双对数函数 $f_4$

衡量指标：总比较次数、Kendall $\tau$秩相关系数（衡量树拓扑变化）。\
输出格式：表 2（行=变换参数，列=4 种方法，单元格为比较次数 / Kendall $\tau$）。\
预期效果：Chen 与 $f_1$比较次数剧烈波动，Kendall $\tau<1$；$f_3$ 与 $f_4$比较次数几乎恒定，且 Kendall $\tau=1$（拓扑完全不变）。\
其他补充：无需引入任何噪声，纯数学变换即可暴露量纲依赖缺陷。

E3 右端奇点与数值溢出压力测试

实验目的：单一验证当 $w\to1$时，Chen 函数因双对数结构导致的数值发散/溢出，以及各类修正函数的边界安全性。\
输入规定：

分布：构造极端热点，$p_1=0.999$，其余均分 $n=1000$个节点。

Oracle：完美频率。直接令预测器输出 $\hat{w}\in{0.9999,0.99999,0.999999}$测试映射结果。\
实验对象：

1. Chen 复合 priority
2. 平滑双对数函数 $f_1$
3. 秩双对数映射函数 $f_3$
4. CDF 平滑秩双对数函数 $f_4$

衡量指标：计算出的最大 priority 数值、是否出现 ==Inf/NaN== 异常、建树所需时间。\
输出格式：表 3（行=方法，列=不同 $\hat{w}$下的最大数值、是否溢出）。\
预期效果：Chen 的 priority 随 $\hat{w}\to1$趋于无穷，可能抛出浮点溢出异常；$f_1,f_3,f_4$ 最大 priority 稳定有界（$O(\operatorname{\log{\mathrm{log}}}{n})$），无溢出。\
其他补充：纯压力测试，专门针对奇点问题。

E4 理论静态最优代价分析

实验目的：单一量化评估“放弃绝对频率”带来的理论代价，验证 $f_2,f_3,f_4$是以静态最优性换取工程鲁棒性。\
输入规定：

分布与规模：同 E1。

Oracle：完美频率预测器。\
实验对象：

1. Chen 复合 priority
2. 平滑双对数函数 $f_1$
3. 线性秩映射函数 $f_2(w)=K-R(w)K/n$（作为极端下界）
4. 秩双对数映射函数 $f_3$
5. CDF 平滑秩双对数函数 $f_4$

衡量指标：静态最优比 $\rho=\frac{实测总比较次数}{\sum_xf_x\mathrm{log}_2(m/f_x)}$（分母为香农熵下界，$\rho$ 越接近常数越优）。\
输出格式：表 4（行=分布，列=5 种方法，单元格为 $\rho$值）。\
预期效果：Chen 与 $f_1$在 Zipf 下 $\rho$最小；$f_2$ 因完全丢弃幅度信息，$\rho$ 全盘偏高；$f_3,f_4$ 在 Zipf 下略差于 Chen，在对抗分布下大幅优于 Chen 和 $f_2$。\
其他补充：此实验是理论分析（权重丢失的 KL 散度损失）的直接实证。

E5 非完美预测器（KL 噪声）鲁棒性测试

实验目的：单一模拟现实预测器存在误差的场景，验证各学习方法在噪声下的优雅降级能力。\
输入规定：

分布：Zipf $\alpha=1$，$n=5000$，$m={10}^5$。

Oracle：噪声频率预测器。通过优化器生成满足 KL 散度 $D_{KL}(P\mid\mid Q)\in{0.1,0.3,0.5,0.7}$的预测分布。\
实验对象：

1. Random Treap（水平基线）
2. Chen 复合 priority
3. 平滑双对数函数 $f_1$
4. 秩双对数映射函数 $f_3$
5. CDF 平滑秩双对数函数 $f_4$

衡量指标：总比较次数、相对退化率。\
输出格式：图 2（横轴 KL 散度，纵轴比较次数的折线图，带误差棒）。\
预期效果：所有 learned 方法均随噪声上升而平滑退化；Random 保持水平线。若 KL 达到 0.7，$f_3,f_4$ 的抗噪性能可能优于直接使用绝对权重的 $f_1$与 Chen。\
其他补充：纯预测器误差测试。

E6 自适应扰动的极端防碰撞测试

实验目的：单一验证固定扰动在密集层下的浮点精度截断缺陷，证明自适应扰动（$\delta∝1/N_k$）在极端长尾分布下的防退化机制。\
输入规定：

分布：极端 Zipf $\alpha=2.0$（大量节点堆积在底层），规模放大至 $n=50,000$。

Oracle：完美频率预测器。\
实验对象：

1. $f_3$+ 固定扰动（$\delta=0.25$）
2. $f_3$+ 自适应扰动（$\delta_{max,k}=\mathrm{min}⁡(0.49,0.1/N_k)$）
3. $f_4$+ 固定扰动
4. $f_4$+ 自适应扰动

衡量指标：同层 Priority 碰撞（完全相等）对数、Treap 最大深度、总比较次数。\
输出格式：表 5（行=方法，列=碰撞数、最大深度、比较次数）。\
预期效果：固定扰动版本底层由于精度耗尽产生大量碰撞，最大深度极度恶化（趋向 $O(n)$）；自适应扰动版本碰撞率近乎为 0，树高完美锁定在 $O(\log{n})$。\
其他补充：此实验专门证明引入自适应的必要性，与算法理论无关，纯属系统级工程修正。

E7 分桶机制的必要性消融（附录）

实验目的：单一验证离散化算子 $Q(f)$对维持 Treap 堆性质（防浮点数截断）的决定性作用。\
输入规定：

分布：Zipf $\alpha=1$，$n=5000$。

Oracle：完美频率。\
实验对象：

1. 无分桶，无扰动：$priority=f_3(w)$
2. 有分桶，无扰动：$priority=Q(f_3(w))$
3. 有分桶，有扰动：$priority=Q(f_3(w))+U(0,0.25)$

衡量指标：Priority 冲突对数、最大树高。\
输出格式：表 6（行=3 种设置，列=冲突数、树高）。\
预期效果：无分桶无扰动因浮点数极微小差异导致底层大量相等，树高直逼 $O(n)$退化为链表；分桶加扰动后完美解决该问题，树高维持在 $O(\log{n})$。\
其他补充：作为附录的理论补丁实验，证明工程细节（如 floor）对算法落地的重要性。
