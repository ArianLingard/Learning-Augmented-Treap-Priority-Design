# 实验设计

本文档规定 E1–E7 七个实验的输入、对象、指标、输出与预期/实际效果。对应实现见 `src/experiment.cpp`，输出 CSV 见 `data/`，绘图见 `notebooks/plot_all.py`（fig1–fig7）。

## 全局统一设置

- **键序**：随机打乱。
- **访问序列长度**：`m = 100000`（E7 为 `20000`）。
- **统计**：每个配置 30 次随机种子，报告「均值 ± 标准差」。
- **预测器公平性**：同组实验内，所有学习增强方法严格共用同一个预测频率 `w_x`。
- **分桶与扰动**：若无特殊说明，统一采用 `Q(f)=⌊f⌋` 分桶，固定扰动 `δ ~ U(0, 0.25)`；Chen 函数自带层间距 1，扰动取 `U(0,1)`。

## 各实验条目说明

每个实验统一按以下字段记录：

| 字段 | 含义 |
| --- | --- |
| 实验目的 | 要验证或解决的问题 |
| 输入规定 | 选什么分布、什么 Oracle（完美频率 / 量纲漂移 / KL 噪声） |
| 实验对象 | 选取哪些 priority 函数 |
| 衡量指标 | 用什么衡量性能 |
| 输出格式 | 图的 X 轴、Y 轴与图类型；CSV 列 |
| 预期效果 | 理论上预期达成什么 |
| 实际效果 | 实验实际达成什么 |

## 实验一：常规分布基础性能对比（E1）

- **实验目的**：综合比较各 priority 函数在常规分布下的查询性能。
- **输入规定**：规模 `n ∈ {1000, 5000}`；分布 Zipf(α=1.0 / 1.25 / 2.0)、Adversarial、Uniform；完美 Oracle（`w_x = p_x`）；`m = 100000`。
- **实验对象**：Random、Chen、f1、f3、f4。
- **衡量指标**：总比较次数、平均深度、最大深度（均值 ± 标准差）。
- **输出格式**：`data/e1_basic.csv`（列：distribution,param,n,method,mean_comparisons,std_comparisons,mean_avg_depth,std_avg_depth,mean_max_depth,std_max_depth）；图 1 为 Zipf α=1 下按方法分组的分组柱状图（X = 方法，Y = 总比较次数 m=10⁵，柱色区分 n）；表 1 为全分布 × 规模的比较次数透视表。
- **预期效果**：偏斜分布下学习增强方法应显著优于随机基线；f3（秩双对数）略优于 Chen。
- **实际效果**：偏斜分布（Zipf、Adversarial）下 f3/f4 比较次数最低、Chen/f1 次之、Random 最差；均匀分布下各方法几乎无差（等权重退化为随机 Treap）。如 Zipf(1.0)、n=5000：Random 1.53×10⁶、Chen 1.05×10⁶、f1 1.07×10⁶、f3 8.30×10⁵、f4 8.78×10⁵。

## 实验二：绝对量纲漂移的鲁棒性（E2）

- **实验目的**：验证尺度序列不变性——预测频率发生严格单调变换（缩放 / 幂律）时，各函数的拓扑是否保持。
- **输入规定**：`n=5000`，真实分布 Zipf(1.0)；对完美频率 `w` 施加变换 `w→c·w`（c=0.1 / 10）与 `w→w^β`（β=0.5 / 2），变换前为完美基线。
- **实验对象**：Chen、f1、f3、f4。
- **衡量指标**：总比较次数、Kendall τ（变换前后 priority 序的一致度，τ=1 表示拓扑完全不变）。
- **输出格式**：`data/e2_drift.csv`（列：transform,param,method,mean_comparisons,std_comparisons,mean_kendall_tau,std_kendall_tau）；图 2 双联：左 X=量纲变换、Y=总比较次数（分组柱状）；右 X=量纲变换、Y=Kendall τ（τ=1 处画参考线）。
- **预期效果**：基于秩的 f3/f4 应对变换保持 τ≈1；依赖绝对量纲的 Chen/f1 应发生拓扑畸变。
- **实际效果**：f3 在所有变换下 τ=1（纯秩，完全尺度不变）；f4 对缩放不变（τ≈1）、对幂律敏感（τ 降至 0.44–0.84，因 CDF 随幂律改变质量分布）；Chen/f1 对缩放敏感（τ=0.76 / 0.90）、对幂律不变（τ=1，因幂律只使双对数产生常数平移）。

## 实验三：右端奇点与数值溢出压力测试（E3）

- **实验目的**：检验右端奇点——预测器过度自信（w→1）时各函数是否浮点溢出。
- **输入规定**：`n=1000`，极端热点 `w₀ ∈ {0.9999, 0.99999, 0.999999, 1.0}`，键 0 取 w₀，其余均分 `(1-0.999)/(n-1)`。
- **实验对象**：Chen、f1、f3、f4。
- **衡量指标**：最大 priority、是否 inf、是否 nan、建树耗时（μs）。
- **输出格式**：`data/e3_singularity.csv`（列：w,method,max_priority,is_inf,is_nan,build_time_us）；图 3 为 max priority 随 w 的折线图（X=预测权重 w，Y=最大 priority）。
- **预期效果**：Chen 在 w=1 时溢出为 +∞；f1/f3/f4 有界（无 inf/nan）。
- **实际效果**：符合预期。w=1 时 Chen 溢出（is_inf=1）；f1/f3 有界且 max priority ≈ 29.90；f4 有界、max priority ≈ −3.16（CDF+1/n 修正把右端压到负值区间，同样无 inf/nan）。

## 实验四：理论静态最优代价分析（E4）

- **实验目的**：以最优静态 BST 为基准，量化各函数相对静态最优的差距，审查构造函数是否留有性能损失。
- **输入规定**：规模 `n ∈ {1000, 5000}`；分布 Zipf(α=1.0 / 1.25 / 2.0)、Adversarial、Uniform；完美 Oracle；`m = 100000`。
- **实验对象**：Chen、f1、f2、f3、f4。
- **衡量指标**：静态最优比 `ρ = 实测总比较次数 / OPT`，其中 `OPT = min Σ f_x·depth(x)` 是按实际访问频率、用 Knuth 动态规划求得的最优静态 BST 代价（ρ ≥ 1，越接近 1 越优）。
- **输出格式**：`data/e4_static_optimal.csv`（列：distribution,param,n,method,mean_rho,std_rho）；图 4 为 n=5000 下按分布分组的分组柱状图（X=分布，Y=ρ，ρ=1 处画参考线）。
- **预期效果**：ρ 应恒 ≥ 1；偏斜分布下秩/CDF 映射（f3/f4）应接近 1，线性秩 f2 因丢弃幅度应明显升高。
- **实际效果**：ρ 恒 ≥ 1。偏斜分布下 f3/f4 最接近 1（f3 ≈ 1.03–1.20）；Chen/f1 居中（≈ 1.11–1.52）；f2 在偏斜分布下显著升高（Zipf(2.0)、n=5000 时 ≈ 6.07）；Uniform 下所有方法 ≈ 1.33–1.38（等权重退化为随机 Treap，深度 ≈ 2·ln n）。

## 实验五：非完美预测器（KL 噪声）鲁棒性（E5）

- **实验目的**：验证各方法在预测器含乘性对数正态噪声（KL 散度可控）下的鲁棒性。
- **输入规定**：`n=5000`，Zipf(1.0)；对完美分布注入乘性噪声 `Q ∝ P·exp(σz)`，二分搜索 σ 使 `D_KL(P‖Q) ∈ {0.1, 0.3, 0.5, 0.7}`。
- **实验对象**：Random、Chen、f1、f3、f4。
- **衡量指标**：总比较次数、相对退化率（= 噪声下比较次数 / 完美基线比较次数）。
- **输出格式**：`data/e5_kl_noise.csv`（列：kl,method,mean_comparisons,std_comparisons,mean_relative_degradation,std_relative_degradation）；图 5 为各方法总比较次数随 KL 的误差棒折线（X=KL 散度，Y=总比较次数）。
- **预期效果**：各学习增强方法随 KL 增大而退化；Random 不依赖预测器，基本不受影响。
- **实际效果**：符合预期。随机基线始终 ≈ 1.52–1.54×10⁶；f3 在低噪声下保持最优（KL=0.1 时 8.48×10⁵），随 KL 增大退化到 9.12×10⁵；相对退化率 f3 从 1.01 增至 1.09，Chen/f1 随 KL 略有上升。

## 实验六：跨桶安全性与自适应扰动（E6）

- **实验目的**：验证固定扰动跨过桶宽（φ ≥ 1）会破坏学习排序，而自适应扰动（δ_max = min(0.49, 0.49·gap)）恒安全。
- **输入规定**：`n=50000`，Zipf(2.0)；固定扰动幅度 `φ ∈ {0.01, 0.25, 0.49, 0.75, 0.99, 1.25, 1.75, 2.0}` 与自适应扰动。
- **实验对象**：f3、f4。
- **衡量指标**：跨桶逆序率（机制指标）、总比较次数与最大深度（后果指标）。
- **输出格式**：`data/e6_adaptive_perturb.csv`（列：method,perturb,mean_inversion_ratio,std_inversion_ratio,mean_comparisons,std_comparisons,mean_max_depth,std_max_depth）；图 6 双联：左 X=φ、Y=跨桶逆序率，右 X=φ、Y=总比较次数，自适应以虚线水平参考线标出。
- **预期效果**：φ < 1 时跨桶逆序率为 0；φ ≥ 1 时逆序率从 0 跳升，查询代价随之上升；自适应恒在安全区。
- **实际效果**：符合预期。f3/f4 在 φ ≤ 0.99 时逆序率恒为 0；φ=1.25 / 1.75 / 2.0 时 f3 逆序率升至 0.007 / 0.034 / 0.046，f4 升至 0.020 / 0.086 / 0.117（比较次数 f4 从 2.35×10⁵ 增至 3.43×10⁵）；自适应扰动逆序率恒为 0。

## 实验七：极端对抗序下的分桶与扰动必要性消融（E7）

- **实验目的**：验证分桶 + 扰动在对抗键序下的必要性（无分桶 / 无扰动时树是否退化为链）。
- **输入规定**：`n=5000`，Zipf(1.0)，`m=20000`；对抗键序——key i 直接取 rank i 的权重（key 0 最热），插入序 = 键序 0..n-1（去掉随机化以暴露退化）。
- **实验对象**：f3 的四种配置——`no_bucket_no_perturb`（连续不分桶不扰动）、`bucket_no_perturb`（分桶不扰动）、`bucket_perturb`（分桶+固定扰动）、`bucket_adaptive`（分桶+自适应扰动）。
- **衡量指标**：树高、总比较次数。
- **输出格式**：`data/e7_bucketing.csv`（列：setting,mean_height,std_height,mean_comparisons,std_comparisons）；图 7 双联：X=配置，Y=树高 / 总比较次数（对数坐标柱状图）。
- **预期效果**：无分桶或分桶但不扰动时树退化为链（树高 = n，比较次数 ≈ m·n/2）；分桶 + 扰动后树高与比较次数回落到 O(log n)。
- **实际效果**：符合预期。`no_bucket_no_perturb` 与 `bucket_no_perturb` 树高 = 5000、比较次数 ≈ 1.10×10⁷（退化为链）；`bucket_perturb` 树高 ≈ 83.7、比较次数 ≈ 4.82×10⁵；`bucket_adaptive` 树高 ≈ 87.6、比较次数 ≈ 4.89×10⁵，下降一个数量级以上。
