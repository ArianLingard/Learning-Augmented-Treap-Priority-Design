# 学习增强 Treap 研究（Learning-Augmented Treap Research）

一个研究 **学习增强（Learning-Augmented）Treap** 中 priority 映射函数设计的实验仓库。项目从 Chen 等人在《On the Power of Learning-Augmented Search Trees》中提出的双对数 priority 出发，系统分析其在真实预测器 / 浮点表示下的工程缺陷，提出并实现一组改进映射函数 `f1`–`f4`，并通过 7 组可复现实验（E1–E7）验证。

核心结论：原始双对数函数在理论上达到静态最优，但存在右端奇点、尺度不敏感和扰动隔离失效等问题；通过"分桶 + 微观扰动"以及用秩 / CDF 替代绝对权重，可以在保持 `O(log n)` 深度的同时显著提升鲁棒性，代价是静态最优性损失由 KL 散度控制。

## 背景与动机

Treap 是 BST 与大根堆的结合：每个节点带一个 priority，priority 越大越靠近根。学习增强 Treap 的思想是，用预测器给出的访问频率 `w_x` 作为 priority 的输入，让"高频访问的节点更浅"，从而逼近静态最优 BST 的熵下界。

Chen 等人的复合 priority 为：

```
priority = -⌊ log2(log2(1/w)) ⌋ + U(0,1)
```

该函数在 `w_x = p_x`（真实频率）时给出期望深度 `O(log(1/p_x))`，总代价 `O(m · Ent(p))`，在常数因子内达到静态最优。但把它直接搬到工程系统时存在几个问题（详见 `Documents and Files/Priority_Design.md`）：

- **右端奇点**：`w → 1⁻` 时 `f(w) → +∞`，预测器过度自信（如 `w = 0.9999`）会引发浮点溢出，极差约束失效。
- **尺度不敏感缺失**：双对数的非线性使 `f(w)` 强依赖绝对量纲，对严格单调变换 `g(w)` 不具备拓扑不变性，预测器更替或数据流量纲漂移时全树需重建。
- **微观扰动隔离不足**：原设定层间距为 1，扰动上界也是 1，没有安全缓冲区，浮点截断或预测噪声下容易发生跨层翻转。

## 核心设计

### priority 函数应满足的性质

设权重集合为 `W_n = {w_1, …, w_n}`，映射函数 `f: D → R`：

1. **层间严格单调保序**：`Q(f(w_x ))>Q(f(w_y ))+δ_max ⟺ E[P(x)] > E[P(y)]`，保证热数据比冷数据更靠近根。
2. **左端点导数发散**：`w → d_min⁺` 时 `|f'(w)| → ∞`，放大长尾极小区间的微小差异，防止海量冷节点坍缩成同一个值。
3. **右端点导数有界**：`w → d_max⁻` 时 `f'(w)` 有界，抑制超级热点独占根节点。
4. **全局极差约束**：设离散化后的层号为 `τ(w)=Q(f(w))`，层间距为 `L`，则要求：`max┬(w∈W_n ) τ(w)-min┬(w∈W_n ) τ(w)=O(loglogn)`


### 工程修正策略

- **分桶（离散化）**：令 `priority = Q(f(w)) + U(0,δ)`，其中 `Q(f) = ⌊f⌋`。强制不同层在浮点表示下至少有 `Ω(1)` 的绝对差值，避免 priority 相等。
- **微观扰动**：桶内注入均匀随机扰动 `ε ~ U(0,δ)`，使同层节点也有区分度，期望深度仍为 `O(log n)`。
- **跃迁隔离**：让高频层与低频层之间有 `Δ > 0` 的安全间隔（如取 `δ = Δ/2`），防止跨层翻转。
- **平滑正则化**：在对数内部加极小常数 `ε`，消除边界奇点，使函数有界。
- **对数弹性有界**：约束 `|d ln f / d ln w| ≤ E`，抑制乘性误差导致的畸变。
- **尺度 / 秩不变**：基于降序秩 `R(w)` 或平滑 CDF `F(w)` 做保序映射，使拓扑仅依赖相对排序。

## 构造的映射函数

所有函数都遵循 `priority = Q(f(w)) + U(0,δ)` 的结构，只需设计确定性部分 `f(w)`：

| 名称 | 公式 | 构造逻辑 | 主要权衡 |
| --- | --- | --- | --- |
| `Chen` | `-⌊log2(log2(1/w))⌋ + U(0,1)` | 原始双对数基线 | 理论静态最优，但右端无界、不尺度不变 |
| `f1` | `-log2(log2(1/w) + ε)` | 保留双对数骨架，内部加 `ε` 抬离奇点 | 改动最小、右端有界；仍依赖绝对量纲 |
| `f2` | `K - ⌊R(w)·K/n⌋`，`K = log2(log2 n)` | 完全抛弃幅度，只保留降序秩 | 完全尺度不变；丢失频率幅度，近似均匀分层 |
| `f3` | `-log2(log2(1/p) + ε)`，`p = (n-R+1)/n` | 把秩归一化成伪概率再套双对数 | 尺度不变 + 双对数分层；假设秩均匀分位 |
| `f4` | `-log2(log2(1/(F(w)+1/n)) + ε)` | 用平滑 CDF 分位数替代离散秩 | 尺度不变、保留局部密度；依赖 CDF 估计质量 |

其中 `R(w) ∈ [1,n]` 为 `w` 的降序排名，`F(w)` 为归一化 CDF，`ε = 1e-9` 为正则常数。

### 静态最优性

当预测器保留绝对频率时，`f1` 在 `w_x = p_x` 下恢复 Chen 的熵下界 `O(m · Ent(p))`。`f2`/`f3`/`f4` 只依赖秩或分位数，达到的是分位数静态最优，其与绝对频率静态最优的差距由 KL 散度 `D_KL(p ‖ p̃)` 控制，实验中用静态最优比衡量：

```
ρ = 实测总比较次数 / Σ_x f_x · log2(m / f_x)
```

## 实验一览

| 实验 | 目的 | 关键配置 | 输出 |
| --- | --- | --- | --- |
| E1 | 常规分布下的基础性能对比 | Zipf(1/1.25/2)、Adversarial、Uniform；n=1000/5000 | `e1_basic.csv` |
| E2 | 绝对量纲漂移鲁棒性（缩放 / 幂律） | `w → c·w`、`w → w^β`；Kendall τ | `e2_drift.csv` |
| E3 | 右端奇点与数值溢出压力测试 | `w = 0.9999 … 1.0`；检测 inf/nan | `e3_singularity.csv` |
| E4 | 理论静态最优代价分析 | 静态最优比 `ρ` | `e4_static_optimal.csv` |
| E5 | 非完美预测器（KL 噪声）鲁棒性 | 乘性对数正态噪声，`D_KL = 0.1…0.7` | `e5_kl_noise.csv` |
| E6 | 自适应扰动 vs 固定幅度扫描 | 固定 `φ = 0.01…2.0` vs 自适应 `δ_max` | `e6_adaptive_perturb.csv` |
| E7 | 分桶 + 扰动必要性消融 | 对抗键序，无分桶 / 分桶 / 固定扰动 / 自适应扰动 | `e7_bucketing.csv` |

全局统一设置：访问序列长度 `m = 100000`（E7 为 20000），每个配置 30 个随机种子，报告均值 ± 标准差；键序随机打乱，同一组实验内各方法共用同一预测频率 `w_x`。

## 主要发现

- **右端奇点（E3）**：`w = 1.0` 时 Chen 函数溢出为 `+∞`，而 `f1`/`f3`/`f4` 均有界（最大 priority 约 29.9），证实平滑正则化与 `+1/n` 修正有效。
- **分桶 + 扰动的必要性（E7）**：对抗键序下，无分桶或分桶但不扰动时树退化成链（树高 = n = 5000，总比较次数约 1.1×10⁷）；加入分桶与扰动后树高降到约 84，比较次数降到约 4.8×10⁵，下降一个数量级以上。
- **静态最优性（E4）**：Chen 与 `f1` 的 `ρ` 稳定接近 1（保留绝对频率）；`f2`（线性秩）在偏斜分布下 `ρ` 明显升高，体现"丢弃幅度"的代价；`f3`/`f4` 在多数分布下 `ρ` 略低于 1，以受控的 KL 散度代价换取尺度不变性。
- **量纲漂移（E2）**：基于秩的 `f3`/`f4` 在缩放 / 幂律变换下保持 Kendall τ ≈ 1（拓扑不变），Chen 与 `f1` 则随量纲变换发生拓扑畸变。
